# LinkArea Universal — Revit 2024

Один DLL: `dist\LinkArea2024_Universal.dll`.
Одна команда в Add-In Manager: **LinkArea2024.UniversalCommand**.

## Запуск

Откройте план зонирования. Выделите одну связь либо одну зону, затем загрузите DLL через Add-In Manager → Manual → Load и нажмите Run на UniversalCommand. Если ничего не выделено, команда предложит выбрать связь или зону.

- **Выбрана связь:** создание одной зоны, охватывающей физическую геометрию выбранной связи по всем этажам. Необязательные вложенные связи выключены по умолчанию.
- **Выбрана зона:** выбор между исправлением границы для СМР и сохранением диагностического отчёта.

## Создание

По умолчанию включён простой контур из четырёх прямых линий, ориентированный по связи, с запасом наружу **20 мм**. Размеры округляются наружу до 1 мм. Если выключить простой контур, строится очищенная выпуклая огибающая.

Марка зоны ставится только по флажку, который изначально выключен.

Можно заполнить корпус и секцию номерами (`4`, `1`) или полными названиями. Новая зона получает:

| Параметр | Пример |
|---|---|
| ФОП_Блок СМР | Корпус 4 |
| ФОП_Секция СМР | Секция 1 |
| ФОП_Описание СМР | Корпус 4_Секция 1 |

Префикс описания выбирается отдельно: без префикса, ОБЩ_, АР_, КР_, ВИС_. Заполнение СМР можно отключить. Три текстовых параметра должны существовать в проекте и быть доступны для записи; отсутствующие параметры команда не создаёт.

## Исправление существующей зоны

Заменяет старую границу выбранной зоны охватывающим прямоугольником из четырёх линий. Сохраняет саму зону и её текстовые параметры. Повторные 20 мм не добавляются: прямоугольник охватывает прежнюю границу.

Общие границы соседних зон, пересечение с чужими границами, каскадное удаление других элементов, изменение параметров либо фактическая граница не из четырёх участков приводят к отмене замены. Успешную операцию можно отменить одним Ctrl+Z.

## Отчёт

Не меняет модель. Сохраняет фактические участки границы, ID линий, координаты, стыки и параметры зоны в `%LOCALAPPDATA%\A101\LinkArea2024\Reports`.

## Проверка и исходники

Версия сборки 2.0.0. .NET Framework 4.8, x64, установленный API Revit 2024. Сборка прошла без ошибок и предупреждений. Проверено по метаданным: ровно одна публичная команда Revit, режим Manual. Локальные тесты контура, проверки границы и формирования значений СМР прошли. Универсальная команда в Revit и совместимость со сторонним СМР на пользовательской модели ещё не проверены.

Исходники сохранены в этой папке. Предыдущий DLL v15 с прежней инструкцией находится в `archive\v15`; отладочные символы итоговой сборки — в `archive\build-symbols`. В `dist` оставлен только итоговый DLL.
